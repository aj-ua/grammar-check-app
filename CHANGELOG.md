# Changelog

The version is set in `Resources/Info.plist` and goes up by one patch number with every update (1.0.3 → 1.0.4). The running version is shown under Settings → General → About.

## 1.0.3
- The selection popup (⌃⌥G) no longer brings the main window forward; it opens on its own and the app you were typing in stays in front.
- Replace pastes straight into the source app and only switches to it if you moved to another app.
- The current version is shown in Settings → General.

## 1.0.2
- Mode dropdown on the main screen and in the selection popup.
- Presets: named extra instructions (audience, tone, spelling variant), managed under Settings → Presets and picked from a dropdown. Two Slack presets are included.
- App icon: a green "G" on black.

## 1.0.1
- First version: paste-and-check window with a word-level diff, ⌃⌥G check and replace of selected text, runs `claude -p` with your Pro login.
